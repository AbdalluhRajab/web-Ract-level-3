# How to add these files to the existing Level 3 project

Copy the files from `src/challenges/` into the project's existing challenge folder.

The existing project already contains a `ChallengeLabPage` and many Level 3 systems. These additions target the challenge areas that need an explicit standalone implementation/check.

Before submission:
1. Import each new challenge into the challenge lab/router used by the project.
2. Run the app and test the flows.
3. Keep only one copy of each challenge.
4. Review the conceptual answers and rewrite them in your own words.
5. Update the README/checklist after testing.

Do not claim a feature is complete unless you have personally tested it.
