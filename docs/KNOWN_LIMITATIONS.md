# Known Limitations / Future Improvements

- The project uses mock/demo API behavior rather than a production backend.
- Authentication is suitable for a local demonstration, not production security.
- Real deployment would require server-side authorization and secure token/session handling.
- Analytics can be extended with richer charts and historical comparisons.
- Accessibility can be audited further with automated and manual testing.
- Additional automated component and end-to-end tests could increase coverage.
